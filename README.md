# 社團宣傳海報生成器 (Club Poster Generator)

專為社團招新、新生茶會、宣傳擺攤設計的**全方位海報生成工具**。免安裝任何軟體或環境，打開瀏覽器即可編輯與匯出高畫質海報！

---

## 🌟 核心特色功能

1. **社團資訊與多社群帳號整合**：
   - 自訂社團名稱、副標題、英文口號。
   - 支援上傳自訂社徽（Logo）或選用 Emoji 圖示。
   - 支援 Instagram（@帳號）、Facebook 粉專、LINE 官方帳號/社群完整呈現。

2. **新生茶會與招新資訊模組**：
   - 包含活動主標題、主題標語、活動日期與入場時間、活動地點、參加對象。
   - 自訂活動特色亮點，自動轉化為精緻彩色膠囊標籤。

3. **吸睛好康標語（小點心與福利）**：
   - 醒目吸引眼球的福利橫幅（如「🎉 現場備有精緻小點心、手搖飲免費享用！」、「★ 早鳥報名加碼送社團特製好禮 ★」）。
   - 可自選 Emoji 圖標與自訂文案。

4. **「握力器挑戰」專屬活動企劃區塊**：
   - 攤位互動小遊戲專用設計，包含「挑戰主題」、「規則說明」。
   - 提供 3 大達標級距（如：男 55kg+ / 女 38kg+ 猛獸組、男 45kg+ / 女 30kg+ 達標組、人人有獎參加獎）與對應獎品設定。
   - 支援一鍵開啟/關閉此模組。

5. **社團活動照片牆**：
   - 支援上傳本機照片（最多 3 張），支援即時替換與清除。
   - 支援 3 種排版佈局切換：**雙圖左右並列**、**單張大焦點圖**、**三圖動態拼貼**。
   - 每張照片均可加入專屬說明標籤。

6. **動態 QR Code 產生器與圖片上傳**：
   - 輸入任何網址（Google 表單報名連結、IG 連結、Line 群），海報右下角即時自動生成清晰可掃描的 QR Code。
   - 亦支援直接上傳已經做好的 QR Code 圖片或專屬條碼。
   - 搭配醒目「行動呼籲標章」與提示說明。

7. **全尺寸支援（實體印刷 & 社群推廣）**：
   - 🖨️ **實體列印規格**：
     - **A4 直式海報** (210 x 297 mm, 學校公佈欄、社辦專用)
     - **A3 大型海報** (297 x 420 mm, 大型展版、活動看板)
     - **B2 特大海報** (500 x 707 mm, 迎新大廳、展架海報架)
   - 📱 **社群推廣規格**：
     - **IG 限時動態 / 豎屏** (9:16)
     - **IG / FB 直式貼文** (4:5)
     - **社群方形貼文** (1:1)

8. **印刷級 300 DPI 超高畫質下載**：
   - 支援 300 DPI 印刷級渲染（匯出尺寸高達 2400x3393 ~ 3600x5090 px），文字銳利無毛邊，可直接交由影印店或印刷廠輸出。
   - 亦支援 2x 高畫質（適合 LINE、IG 發文）與 1x 快速預覽。

9. **多款主題風格一鍵切換**：
   - 🔥 **熱血活力紅黑風**（健身、體適能、球類、極限運動社團）
   - ⚡ **潮酷黑金潮流風**（熱舞、電競、DJ、潮流音樂社團）
   - 🌿 **日系清新青綠風**（文藝、志工、戶外休閒、生活品味社團）
   - 🌊 **晨曦陽光藍白風**（學術、音樂、清新校園社團）
   - 💜 **夢幻炫彩紫粉風**（設計、藝術、多媒體動漫社團）

10. **離線可用與自動存檔**：
    - 完全離線運作，資料與上傳圖片自動保存在本機瀏覽器（LocalStorage），重整網頁不丟失。
    - 附有「重設範本」功能，可隨時一鍵還原預設精緻版面。

## 🚀 如何開始使用？

### 方式一：雙擊開啟（最簡單）
直接雙擊點開專案資料夾內的 **`index.html`** 或 **`啟動海報生成器.bat`**，即可在 Chrome / Edge / Firefox 瀏覽器中開始使用！

### 方式二：本機伺服器開啟（可選）
如欲使用本機 HTTP 伺服器，可在本目錄開啟終端機執行：
```bash
python -m http.server 8080
```
然後瀏覽 `http://localhost:8080` 即可。
